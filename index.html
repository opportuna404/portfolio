01. Raffle & LeadGen Funnel Bot

Геймифицированная воронка розыгрыша призов с интерактивным кубиком, контролем спонсоров и скриншотами.

ТЗ

Telegram-бот для массового привлечения и прогрева аудитории через механику розыгрыша с квалификацией лидов.

  1. Запуск (/start) и витрина: Демонстрация 6 коллекционных призов (iPhone 16 Pro Max, AirPods Pro 2, TG Premium, PS5 Slim, Stars, MacBook Air), кнопки условий и отзывов.
  2. Бросок кубика (send_dice): Интерактивный бросок кубика 🎲 с фиксацией выпавшего подарка (1–6) за аккаунтом в базе данных.
  3. Сдача заданий (10 скриншотов): Загрузка скриншотов с комментариями и динамическим счетчиком: [🟩🟩🟩⬜️⬜️⬜️] 3/10.
  4. Проверка подписки на спонсоров: Автоматическая валидация подписки через метод Bot API get_chat_member.
  5. Верификация и номерной билет: Финальная символическая оплата (1 ₽) и генерация уникального билета участника (#RAFFLE-2026-71431).
  6. Панель администратора: Сквозная конверсия воронки по всем 5 шагам (/admin) и список финалистов.
Python 3.12 · aiogram 3 · aiosqlite · Bot API 02_LeadGen_Funnel_Bot

02. Shop Digital Goods Bot

Магазин цифровых товаров с балансом, автовыдачей ключей и панелью управления.

ТЗ

Автоматизированный интернет-магазин цифрового контента (VPN-ключи, игровые доступы, AI-подписки) с моментальной доставкой данных.

  1. Двухуровневый инлайн-каталог: Категории товаров с пагинацией, ценами, остатками на складе и описанием.
  2. Внутренний баланс: Личный кабинет пользователя с историей пополнений, статистикой расходов и ID.

  5. Панель администратора: Добавление категорий и товаров через интерфейс бота, загрузка батчей ключей и статистика выручки.

03. Service Booking & Client Cabinet Bot

Сервис онлайн-записи и личный кабинет клиента с интерактивным календарем.

ТЗ

Система онлайн-записи для сферы услуг (салоны, барбершопы, студии) с выбором мастера, даты и слотов времени.

  1. Каталог услуг и мастера: Список процедур с длительностью и ценами, выбор конкретного мастера или «Любой свободный».

  5. Управление визитами: Отмена записи клиентом в 1 клик с моментальным освобождением слота в расписании.

04. Marketplace Price Alert Bot

Мониторинг цен Wildberries по артикулу с CDN-парсингом и фоновыми пуш-алертами.

ТЗ

Асинхронный бот-мониторинг для селлеров и покупателей маркетплейса Wildberries с прямым CDN-парсингом без блокировок.

  1. Распознавание ссылок и артикулов: Прием числового артикула или веб-ссылки любого формата с извлечением ID товара через Regex.
  2. Парсинг через CDN Wildberries: Получение бренда, названия, актуальной цены и фото напрямую из CDN-кластера wbbasket.
  3. Режимы отслеживания: Уведомление о любом снижении цены либо установка целевого ценового порога.
  4. Асинхронный воркер: Фоновый опрос цен через asyncio.create_task с расчетом процента скидки и экономии.
  5. Пуш-карточки уведомлений: Сообщение с фотографией товара, зачеркнутой старой ценой, новой скидкой и ссылкой на покупку.

05. AI Customer Support Bot

Двухуровневая поддержка: ответы базы знаний/LLM + живой чат с ответом через Telegram Reply.

ТЗ

Гибридная служба поддержки для e-commerce: автоматические консультации по FAQ и эскалация на оператора.

  1. Автоматический FAQ-уровень: Мгновенные ответы на типовые вопросы (доставка, оплата, гарантия, возврат) по ключевым словам + интеграция с LLM.

  4. Тикетная система: Сохранение полной истории переписки, статусов (open/closed) и ролей отправителей в БД.
  5. Оценка качества (CSAT): Запрос оценки от 1 до 5 звезд при завершении диалога со сбором статистики для руководства (/stats).

06. Crypto VIP Club Bot

Монетизация закрытых каналов: оплата USDT/Stars, одноразовые инвайты и авто-кик.

ТЗ

Платформа платного доступа в закрытые VIP-каналы и чаты с приемом криптовалюты и автоматическим контролем участников.

  1. Криптоплатежи и Telegram Stars: Интеграция с официальным Crypto Pay API (USDT, TON, BTC) и нативными звездами Telegram.
  2. Одноразовые инвайты: Создание персональной ссылки через Bot API с лимитом member_limit = 1 для защиты от сливов.
  3. Контроль срока подписки: Фоновый воркер проверяет даты окончания, отправляет предупреждение за 24 часа до списания.
  4. Автоматический кик: Исключение пользователя из канала (ban_chat_member + unban), если подписка не продлена.
  5. Кабинет резидента: Просмотр активного тарифа, оставшихся дней и моментальное продление доступа.
